The pipeline

From raw data to the printed atlas

Analysis ran entirely in open tooling, so any number can be reproduced by re-running the same scripts against the same sources.

1

Source acquisition

CBS Population & Housing Census 2021 ward tables for demographics; the six-sector fieldwork dataset compiled in a Microsoft Excel workbook; SRTMGL1 30 m DEM from USGS; OpenStreetMap roads; ESA WorldCover 2021 for land cover.

2

Clean & standardise

Raw survey entries were cleaned and standardised in pandas. The workbook underwent a structured quality-control pass where 31 figures were corrected against cross-checks.

3

Demographic analysis

R / ggplot2 produced the 60-chart demographic suite — pyramids, ward lollipops, projections and norm-dumbbell gaps. Projection models spanned linear, exponential and cohort-component methods.

4

Spatial analysis

GDAL + QGIS 3.x built the thematic rasters: hillshade, land cover, flood and landslide grids, and the multi-criteria land-suitability weighted overlay, plus the road-network and buffer analyses.

5

Report assembly

A custom Python render pipeline (python-docx / report engine) laid the charts and maps into the IUDP report chapters, the Social Development Plan, and the detailed project reports.

6

Web build

QGIS print-composer images and chart files were exported and copied into this zero-build static site — Leaflet for the interactive map, the Python exports for the gallery.

Coordinate systems

How the coordinates work here

Two CRS are used deliberately. WGS 84 (EPSG:4326) is the analytic and web CRS for maps on this site; UTM 45N (EPSG:32645) is used for any area or length calculations to preserve true metric distances on the sloped terrain.

EPSG:4326WGS 84 (Lon/Lat)

Geographic CRS used for the Leaflet map and all styled image overlays on this site. Rasters were warped to 4326 for web display.

EPSG:32645UTM Zone 45N

Projected CRS for area and length computations (e.g. land-suitability cell areas, road lengths, hectare figures) where metric accuracy matters.

Why it matters. Distances on an unprojected 4326 canvas distort on steep gradients; all reported lengths and areas in the plan (roads, buffers, per-ward statistics) therefore pass through 32645.
Quality control

The 31 workbook corrections

A structured Q&A pass over the six-sector fieldwork workbook found and fixed errors before analysis — a representative set below. All corrections were logged for auditability.

  • F1Health-post bed/ratio values aligned to DUDBC staffing norms.
  • F2Vehicle and bus-depot counts reconciled against municipal records.
  • F3Road length re-measured in UTM 45N (not 4326 straight-line).
  • F4School enrolment totals summed from grade-wise returns.
  • F5Waste-generation tonnage scaled to population, not households.
  • F6Livestock and crop figures recomputed from ward visits.
  • F7Drinking-water coverage corrected to household connections.
  • F8Historic budget figures re-based to the audited FY 82/83.
